# Metaphor bank and metaphor engine — The Parent Code

How to use: **grep** this file for the idea in the line (`grep -i "trust\|secret" references/metaphor-bank.md`),
never read it whole in the chat. If nothing fits, run the **metaphor engine** (§1) — it turns any new idea
into a bold, physical picture that belongs to this video's story.

>   worked back here after every video.

>   already carry; real everyday moments carry the everyday lines. Not every line needs a metaphor.

>   parent quietly sitting next to a teenager; a teen looking away but still listening; a hand reaching out; a parent

>   uncomfortable; a parent kneeling down to the child's level; two people sitting together without needing a heart

## 1. The metaphor engine — for any idea, including ones never seen before
0. **First ask whether a real moment carries it better** — an everyday situation parents and teens recognise, or a
   behaviour between the two of them. If it does, use that; the metaphor is only for meaning the real moment can't show.
1. **Name the idea and the feeling** in the line (e.g. "the rule feels unfair" → resentment, powerlessness).
2. **Pick a physical lens** that carries that feeling:
   weight (heavy/light) · size (grows/shrinks) · distance (far/near, gap, wall) · containment (box, cage,
   bubble, room) · temperature (frozen/boiling) · pressure (kettle, a shaken bottle, a rattling lid) · speed (running,
   chasing, treadmill) · balance (tightrope, seesaw, scales) · light and dark (spotlight, shadow room,
   lighthouse) · growth and decay (plant, crack, rust) · connection (rope, bridge, wire, thread) · noise
   (bubbles, buzzing, alarms) · time (clock, hourglass, calendar, moon) · direction (fork, maze, path,
   compass) · weather (storm, fog, sunrise) · building (blocks, bricks, scaffolding) · games (boxing ring,
   chess, tug-of-war, scoreboard) · journeys (river stones, mountain, ladder, bus stop) · machines (gears,
   switch, plug, battery) · water (sea, drowning, life ring, rising tide).
3. **Tie it to the story:** use the video's spine object (the phone, the homework, the clock…) or a
   motif inside the metaphor, so it grows out of the story instead of arriving at random.
4. **Put a character inside it reacting** — the metaphor is something that happens to MOM or SON.
5. **Make it move:** plan the transformation as an in-scene edit (it grows, rises, cracks, lifts, sinks).
6. **Plan its return only if it will mean something new:** the same metaphor comes back later changed and
   saying something different (the wall comes down, the vault opens, the kettle is taken off the boil) — that is what makes
   it a story, not decoration. It never returns only because it looks good.
7. **Check the tests:** readable at a glance with the sound off; one bold idea, not a pile of props; it
   amplifies the line instead of repeating its noun; it is mature (a real thing a parent would recognise,
   not a kids' icon).

## 2. Metaphor through-lines — why it never feels random
Each video picks the metaphor families its themes need in the plan (e.g. "the lockbox that grows", "the
river of stepping stones", "the kettle coming to the boil") and returns to them only when each return means something
new: set up, escalate, resolve. Around them sit one-off surprises — short metaphors as pattern interrupts.
A one-off must still touch the spine object or a motif. Log the family in each metaphor beat's `metaphor`
field.

## 4. Rules for using the bank
- First ask whether a real everyday moment or a behaviour carries the line better; use the metaphor only for meaning
  the words and the real moment don't carry.
- Pick by **the idea and the feeling in the line**, then tie it to the video's spine object or a motif.
- Prefer a through-line family over a new one-off; one-offs are short metaphors used as pattern interrupts.
- A character reacts inside it; the transformation is an in-scene edit; it returns only with a new meaning.
- One bold idea per frame; white or very light neutral ground, the metaphor's key object carries the one colour.
- Mature, never childish: no hearts, stars, trophies, podiums, smile masks, emoji-style icons, cartoon creatures or picture
  bubbles standing in for a feeling.
- Never use a metaphor to fill space: every metaphor answers "what does this line feel like?".
- After every video, add the new metaphors that worked to this bank.
